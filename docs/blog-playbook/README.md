# 블로그 작성 규칙

네이버 블로그에 하루 2편, 검색으로 들어온 독자를 내 사이트로 보내는 정보 글을 쓰는 규칙이다. 지금은 kosnas.com('투자' 카테고리)용이고, 다른 프로젝트에 쓸 때는 아래 네 가지만 바꾼다.

- **연결할 사이트와 화면:** kosnas는 대시보드와 /kr 섹터 화면. 캡처는 이 화면들에서만 고른다.
- **키워드 순서표:** 그 분야의 네이버 키워드 도구 결과로 새로 만든다(KEYWORDS.md).
- **블로그 카테고리와 독자:** kosnas는 '투자' 카테고리, 개인 투자자.
- **쇼핑커넥트 상품군:** 그 독자의 생활 고민에서 고른다.

## 주제와 키워드

주제는 그날 트렌드에서 고르고, 검색어는 키워드 순서표에서 고른다. 새 블로그는 큰 검색어에서 올라가기 어렵다.

- **트렌드:** 최근 24시간 증시·경제 뉴스에서 가장 많이 다룬 이슈 1~3위. 트렌드는 주제(사람들이 지금 궁금해하는 질문)를 고르는 데만 쓴다.
- **메인 키워드:** 키워드 순서표에서 아직 안 쓴 것을 위에서부터, 그날 이슈와 맞는 것을 먼저. 모바일 월 검색 2천~4만대 중간 검색어가 메인, 큰 검색어는 서브. 쓴 줄에는 ✅와 날짜.
- **2편은 서로 다른 화면:** 하나는 대시보드, 하나는 /kr처럼 연결 화면을 나눈다.
- **키워드 넣는 자리:** 제목 맨 앞, 3줄 요약 첫 줄, 소제목 2개 이상, 본문 전체 4~6회(억지 반복 금지), 해시태그 첫 태그. 서브 키워드 2~3개도 자연스럽게.
- **이슈 이름:** 그날 많이 검색될 종목·사건 이름은 제목에 넣어도 된다. 본문은 여전히 오래 읽히는 원리로.
- **빼는 검색어:** 업체·수수료·리딩방·종목 추천처럼 광고·권유 성격이 강한 것.

## 글 구조와 문체

하루만 지나도 쓸모없는 글은 쓰지 않는다. 날짜·오늘·어제, 그날 지수·종가·수급 금액은 넣지 않고, 질문 하나에 답하는 원리·판단 기준·보는 법을 쓴다. 단순 장 정리도 쓰지 않는다.

1. **제목:** 메인 키워드 + 훅, 30자 안팎. '~가 갈리는 이유', '~신호 3가지', '~보는 법'. 장이 어떻든 희망 쪽 프레임, 약속·권유 금지.
2. **대가성 문구:** 제목 바로 아래 "이 포스팅은 네이버 쇼핑커넥트 활동의 일환으로, 판매 시 수수료를 받을 수 있습니다."
3. **3줄 요약:** ✓ 세 줄, 핵심 숫자 포함.
4. **01~04 번호 소제목:** 독자의 질문 말투. 01 왜 그런가, 02 예시 계산, 03 볼 신호 ①②③, 04 내 화면에 적용(사이트 연결).
5. **예시 계산:** 02에 가정 숫자 목록('- '로 시작) + '계산식은 이렇습니다.' 한 줄.
6. **04 끝:** 사이트 화면 한 단락 + 👉 링크 하나.
7. **면책:** ※ 수치는 가정이며 매수·매도 권유가 아닙니다.
8. **해시태그 10개:** 첫 태그 = 메인 키워드.

존댓말, 문단 2~4줄, 본문 1,200~1,800자. 인사말·서론·맺음말 없음. 형식은 조회수 높은 블로그를 벤치마킹했고 내용은 베끼지 않는다.

## 쇼핑커넥트 끼워 넣기

상품은 별도 글이 아니라 03 끝에 2~4줄 여담으로 넣는다. 글의 주인공은 계속 투자 내용이다.

- **다리:** 투자자의 생활 고민 하나(눈·목·허리, 밤 미장과 수면, 모니터 환경 등)로 "하나 덧붙이면,"으로 시작.
- **압축 PASONA:** 고민 → 고르는 기준 두 가지 → 단점 하나 인정 → 이런 분께 → "리뷰가 많은 제품의 실제 후기는 아래에서 비교해 보실 수 있습니다."
- **쓰는 법:** 카테고리와 기준만, 상품명 없음. 1인칭 경험 금지("~쓰는 분이 많습니다"). 건강기능식품은 치료·예방 표현 금지.
- **역할:** 카테고리와 브랜드커넥트 검색어는 작성자가 제시, 상품 선택과 링크 발급은 블로그 주인. 필터는 수수료 10% 이상·리뷰 500개 이상.
- **주의:** 본인·가족이 자기 링크로 사면 실적 무효. 같은 상품군을 연달아 쓰지 않는다.

## 그림과 붙여넣기 서식

글은 복사 페이지의 '글 복사' 버튼 → 네이버 에디터 본문에 Ctrl+V로 서식째 넣고, 그림은 하나씩 복사해 붙인다. HTML 코드를 복사하면 태그가 그대로 들어가고, 글과 함께 복사한 그림은 에디터가 '허용되지 않는 형식'으로 뺀다.

그림 두 장(직접 만든 인포그래픽, 1080px, 어두운 남색 바탕·노랑/민트 강조·Noto Sans KR):
- 표지: 제목 + 큰 숫자 하나 + 핵심 3줄. 3줄 요약 바로 아래.
- 계산표: 02의 예시 계산을 표로. 예시 계산 목록 바로 아래.
- 사이트 캡처는 별도로 최대 2장.

| 부분 | 서식 |
| --- | --- |
| 제목 | 에디터 제목 칸에 따로 |
| 대가성 문구 | 작은 회색 글씨, 가운데 |
| 3줄 요약 | 굵게, 가운데 정렬 |
| 소제목(01~04) | 크고 굵게, 번호만 민트색. 다음에 한 줄 띄움 |
| 소제목 본문 끝 | 다음 소제목·면책 앞에 두 줄 띄움 |
| 소소제목(①②③) | 본문 크기 굵게, 바로 다음 줄에 설명. 블록 사이 한 줄 |
| 본문 | 왼쪽 정렬, 진한 글자색 |
| 계산식 줄 | 기울임 |
| 👉 사이트 주소 | 굵게, 가운데, 눌리는 하이퍼링크 |
| 면책·해시태그 | 작은 회색 / 민트색 |

## 하지 않는 것

- 매수·매도 권유, '반드시 오른다'·'지금 사라' 같은 약속.
- 날짜·그날 수치에 묶인 내용, 단순 장 정리.
- 글 파일에 [제목]·[캡처]·[여기에 …] 같은 표시 괄호·빈칸. 첫 줄 = 제목, 마지막 줄 = 해시태그.
- 사이트 안내문 문장 복사(중복 문서), 벤치마킹한 블로그 내용 베끼기.
- 쇼핑커넥트 상품명·과장·수익 약속·상세 페이지 캡처.
- 글 작업을 하면서 사이트 저장소 손대기.
- 발행 뒤 큰 수정 반복.

## 매일 작업 순서와 도구

1. 웹 검색 한 번으로 최근 24시간 이슈 1~3위 확인.
2. 편마다 키워드표에서 메인 키워드를 고르고 글 txt 저장(YYYY-MM-DD_N_주제.txt).
3. 그림 설정(spec JSON) 작성 → `img-tool/build.py`로 표지·계산표 PNG.
4. `img-tool/mkcopy.py <txt> <표지png> <계산표png> <out.html>`로 서식 복사 페이지를 만들어 고정 주소에 다시 올림.
5. 키워드표에 ✅와 날짜.
6. 블로그 주인에게 메시지: 트렌드 한 줄, 편마다 복사 페이지 링크·메인 키워드·제목·쇼핑커넥트 카테고리와 검색어·캡처 화면.

블로그 주인 몫(블로그 지수): 매일 같은 시간대 발행, 같은 주제 유지, 서로이웃·댓글 하루 10분, 하루 뒤 네이버 '블로그' 탭에서 제목이 검색되는지 확인. 새 블로그는 2~4주 조회 0~1이 흔하다.

`img-tool/` 설치·사용법은 `img-tool/README.txt`. build.py의 `BLOG` 경로는 프로젝트마다 바꾼다.
